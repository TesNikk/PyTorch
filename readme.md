
# PyTorch Learning Journey

A comprehensive collection of PyTorch projects spanning fundamentals to advanced deployment.

## 📚 Curriculum Structure

### [PyTorch Fundamentals](./PyTorch_Fundamentals)
- **Module 1**: Tensor operations, neural networks, activation functions
- **Module 2**: MNIST classifier with MLOps
- **Module 3**: Data management and pipelines
- **Module 4**: CNN architectures and overfitting mitigation

### [PyTorch Techniques & Ecosystem](./PyTorch_Techniques_and_Ecosystem_Tools)
- **Module 1**: Hyperparameter tuning, schedulers, Optuna
- **Module 2**: Torchvision, transfer learning, preprocessing
- **Module 3**: NLP, tokenization, text classification, embeddings
- **Module 4**: PyTorch Lightning, performance profiling, optimization

### [Advanced Architecture & Deployment](./Pytorch_Advance_Architecture_Deployment)
- **Module 1**: Siamese networks, ResNet, DenseNet architectures
- **Module 2**: CNN visualization, saliency maps, diffusion models
- **Module 3**: Transformers, attention mechanisms, seq2seq translation
- **Module 4**: Model quantization, pruning, ONNX export, MLflow

## 🎯 Key Topics
- Neural network design and training
- Computer vision (classification, segmentation, detection)
- Natural language processing
- Model optimization and deployment
- Advanced architectures (CNN, Transformer, GAN variants)

## 📂 Project Structure
Each module contains:
- `*.ipynb` - Interactive notebooks with explanations
- `helper_utils.py` - Utility functions
- `unittests.py` - Unit tests for validation
- Data folders with datasets
